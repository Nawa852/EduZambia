## 1. Executive Summary & National Framework Context

Zambia’s Ministry of Education (MoE) and the Curriculum Development Centre (CDC) have instituted the **Zambia Education Curriculum Framework 2023 (ZECF 2023)**, officially restructuring the national education system from **4-7-5-4** to **3-6-6-3**:
- **Early Childhood Education (ECE):** 3 years (Ages 3–5).
- **Primary Education:** 6 years (Grades 1–6).
- **Secondary Education:** 4 years Ordinary Level (Forms 1–4) leading to the School Certificate Examination, followed by 2 years Advanced Level (A-Levels / Forms 5–6).
- **Dual Pathways at Secondary Level:** Academic Pathway vs. Technical/Vocational Pathway.

For Synapse, supporting **both** the existing Examinations Council of Zambia (ECZ Grades 10–12) framework and the new CDC Competence-Based Curriculum (Forms 1–4 and Primary) provides national coverage and preserves the value of historic ECZ past papers.

## 3. Automated PDF Text Ingestion Pipeline & Encoding Decoder

The official ZEPH camera-ready PDFs published on `edu.gov.zm` use a custom font-encoding glyph offset where characters are shifted by exactly **+29** relative to standard ASCII.

### Automated Decoder Function (Python)
```python
def decode_cdc_glyph_stream(raw_text: str) -> str:
    """
    Decodes ZEPH 2024 camera-ready PDF text streams.
    Characters in the printable shifted range are mapped back using:
    char_code = ord(glyph) + 29
    """
    decoded_chars = []
    for ch in raw_text:
        code = ord(ch)
        if 3 <= code <= 97:
            decoded_chars.append(chr(code + 29))
        elif ch in '\n\r\t ':
            decoded_chars.append(ch)
        else:
            decoded_chars.append(ch)
    return "".join(decoded_chars)
```

Running this decoder transforms raw glyph streams like `5HSXEOLF RI =DPELD 0,1,675< 2) ('8&$7,21` directly into clean, standardized text: `REPUBLIC OF ZAMBIA MINISTRY OF EDUCATION`.
